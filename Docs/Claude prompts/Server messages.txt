⏺ Perfect! I can see the pattern. The *Props types and *Payload types are identical, and you're doing unnecessary
  destructuring and reconstruction. Here's how to simplify:

  Best approach - Generic message creator:

  // Generic helper function
  function createMessage<T extends string, P>(
    type: T,
    payload: P
  ): Message<T, P> {
    return { type, payload };
  }

  // Now your functions become simple one-liners
  export function genericServerMessage(
    payload: GenericServerMessagePayload,
  ) {
    return createMessage(SERVER_MESSAGE_GENERIC_MESSAGE, payload);
  }

  export function serverChannelUserList(
    payload: ChannelUserListServerMessagePayload,
  ) {
    return createMessage(SERVER_MESSAGE_CHANNEL_USER_LIST, payload);
  }

  This eliminates:
  - The separate *Props types (just use the *Payload types directly)
  - The destructuring and reconstruction
  - The verbose return type annotations (TypeScript infers them)

  Alternative - If you want even less code:

  const createMessageFactory = <T extends string, P>(type: T) =>
    (payload: P): Message<T, P> => ({ type, payload });

  export const genericServerMessage = createMessageFactory(SERVER_MESSAGE_GENERIC_MESSAGE);
  export const serverChannelUserList = createMessageFactory(SERVER_MESSAGE_CHANNEL_USER_LIST);
